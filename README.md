# Marking AIS

MVP автоматизированной информационной системы маркировки учебников.

## Stack
- Java 21
- Spring Boot
- Maven
- React + Vite
- In-Memory Repository на первом этапе
- Billing через отдельный интерфейс
- PostgreSQL подключается после Billing

## Development stages
1. AIS Core + In-Memory
2. Billing
3. PostgreSQL
4. Integrations and infrastructure
